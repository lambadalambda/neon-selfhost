# Improve branch list management

## Summary

Keep branch navigation and management usable as branch count grows.

## Requirements

- Add explicit sorting and bounded pagination.
- Add rename and optional expiration policies.
- Improve lineage visualization and protected/default indicators.
- Keep endpoint-specific actions visible without cluttering every row.

## Acceptance Criteria

- Hundreds of branches remain searchable and navigable.
- Rename and expiration preserve lineage and endpoint consistency.
- Destructive actions remain confirmed and policy-aware.

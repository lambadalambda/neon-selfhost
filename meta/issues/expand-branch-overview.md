# Expand branch overview

## Summary

Turn branch overview into the primary branch operations and inspection page.

## Requirements

- Add create-child-branch shortcut and explicit lineage.
- Show branch/tenant/timeline identifiers, endpoint state, active connections, and errors.
- Add child branches and databases sections.
- Link to restore, operations, SQL, and endpoint controls.

## Acceptance Criteria

- Operators can understand branch identity, lineage, connectivity, and health in one place.
- Identifiers have safe copy actions.
- Missing runtime data is labeled rather than inferred.
